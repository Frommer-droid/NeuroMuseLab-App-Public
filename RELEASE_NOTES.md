# История изменений (Release Notes)

## Версия 0.7.0 (2026-09-29)

*Публичная обезличенная версия с локальными настройками, проверяемой сборкой и русскоязычным установщиком.*

### ✨ Новые возможности

- Ссылка кнопки под публикацией стала необязательной: пустое поле отправляет пост без кнопки.
- Добавлена английская документация и инструкция по запуску из исходников.
- Добавлен русскоязычный установщик; установленная версия хранит настройки отдельно в профиле каждого пользователя.

### 🎨 Интерфейс

- Оформление основного окна и сборщика приведено к палитре One Dark.

### 🛡️ Безопасность

- Убрана встроенная индивидуальная ссылка; значение хранится только в локальном `settings.json`.
- Сборка копирует только явно разрешённые ресурсы и останавливается при постороннем происхождении native DLL.

### 🛠 Улучшения

- Добавлены проверка происхождения файлов в `COLLECT-00.toc`, согласованности MSVC runtime и неинтерактивный frozen smoke.
- Добавлена лицензия MIT для собственного кода проекта.

## Версия 0.6.1 (2026-03-27)

*Патч-релиз с исправлением кнопки доната на обложке в multi-audio публикации.*

### 🐛 Исправления ошибок
- Исправлен сценарий публикации с обложкой и несколькими `mp3`: первое изображение теперь всегда отправляется с inline-кнопкой «Поддержать автора донатом».

### 🛠 Улучшения
- Синхронизированы UI-подсказки, `README.md` и `DEVELOPER.md` с фактической логикой публикации обложки при нескольких аудио.
- Обновлены регрессионные тесты сервиса Telegram для сценария `cover + multi-audio`.

## Версия 0.6.0 (2026-03-20)

*Релиз с возвращением сценария публикации нескольких аудио без потери inline-кнопки доната под каждым сообщением.*

### ✨ Новые возможности
- Добавлен интерфейс выбора нескольких `mp3` с динамическими строками и кнопками `+` / `×`.
- Реализована последовательная отправка нескольких аудио: каждое `mp3` публикуется отдельным сообщением с inline-кнопкой «Поддержать автора донатом».

### 🐛 Исправления ошибок
- Исправлен сценарий multi-audio публикации: вместо неподходящего Telegram-альбома приложение отправляет несколько стандартных аудио-сообщений подряд.
- Исправлен общий поток публикации с обложкой и текстом для нескольких аудио: обложка теперь отправляется один раз перед первым треком, стихотворение — один раз после последнего.

### 🛠 Улучшения
- Убран искусственный лимит на количество аудиофайлов в форме публикации.
- Расширен `settings.json`: список аудиофайлов сохраняется и восстанавливается между запусками.
- Добавлены тесты на последовательную multi-audio отправку, остановку на ошибке, новый UI-виджет списка файлов и persistence настроек.

## Версия 0.5.0 (2026-02-23)

*Релиз с внедрением адаптивного масштабирования UI и улучшением читаемости интерфейса на разных DPI/экранах.*

### ✨ Новые возможности
- Добавлено универсальное адаптивное масштабирование UI с расчетом `auto_percent` и пользовательской поправкой `delta_percent`.
- В статус-бар добавлен контрол `Масштаб:` с выбором поправки `-50..+50` (шаг `10`) и сохранением значения в `settings.json`.
- Добавлена динамическая реакция на смену экрана и DPI: перенос окна между мониторами автоматически пересчитывает масштаб.

### 🐛 Исправления ошибок
- Исправлены визуальные артефакты в статус-баре: убраны белые рамки у контейнеров элементов масштаба.
- Исправлено поведение первого запуска: окно и минимальные размеры теперь рассчитываются с учетом итогового масштаба.

### 🛠 Улучшения
- Вынесены формулы масштаба в отдельный сервис `app/services/ui_scale_service.py`.
- Расширена модель настроек: добавлены `ui_scale_mode`, `ui_scale_delta_percent`, `ui_scale_percent` с миграцией legacy-ключей.
- Добавлены unit-тесты для формул масштаба и миграции настроек (`tests/test_ui_scale_service.py`, `tests/test_settings_ui_scale.py`).

## Версия 0.3.2 (2026-02-21)

*Патч-релиз с обновленным сценарием одиночной публикации и inline-кнопкой под обложкой.*

### ✨ Новые возможности
- Для одиночной публикации с обложкой реализован порядок: изображение с inline-кнопкой доната -> аудио с inline-кнопкой доната -> текст стихотворения отдельными сообщениями.
- Под сообщением с изображением добавлена inline-кнопка «Поддержать автора донатом».

### 🐛 Исправления ошибок
- Исправлена отправка стихотворения при наличии обложки: текст больше не отправляется в подпись к изображению и не упирается в лимит `1024`.

### 🛠 Улучшения
- Обновлены UI-подсказки по лимитам и логике отправки текста.
- Добавлены регрессионные тесты сервиса Telegram на порядок отправки и передачу inline-клавиатуры.
- Синхронизированы `README.md` и `DEVELOPER.md` с новым сценарием публикации.

## Версия 0.3.1 (2026-02-20)

### 🛠 Улучшения
- Добавлены регрессионные тесты для парсинга исполнителя и названия трека из имени файла.
